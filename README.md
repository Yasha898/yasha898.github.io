# Yash Patil — Data Analyst Portfolio

A responsive, static portfolio website using HTML, CSS, and JavaScript. No build tools or paid hosting are required.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and contact form behavior
- `assets/Yash_Patil_Resume.pdf` — downloadable resume

## Preview on your computer
1. Extract the ZIP file.
2. Open the `yash_data_analyst_portfolio` folder.
3. Double-click `index.html` to open it in Chrome or Edge.

The Google Fonts import needs an internet connection; the page still works if fonts cannot load.

## Important: personalize before publishing
Your LinkedIn and GitHub profile links are already configured in the introduction and contact sections. Verify them before publishing.

The latest approved AlphaSense-tailored resume is included at `assets/Yash_Patil_Resume.pdf` and is used by the Download Resume button.

The contact form uses `mailto:` and opens the visitor's default email app; it does not send messages directly from the website or store them. For a form that submits online without requiring an email app, connect a service such as Formspree and update the form script.

## Free publishing with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a new public repository, for example `yash-patil-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root (not the ZIP itself).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show the published website URL in the Pages settings.

Before sharing the link, test the site on mobile and desktop, click the resume download, and verify your social profile URLs.
